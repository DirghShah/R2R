Sources were shot on an iPhone 17 Pro at 1206 × 2622, the 6.3" class, which the
listing does not accept. Upscaled rather than reshot: the aspect ratios differ
by 0.065%, so nothing is cropped and nothing is visibly stretched. The Simulator
was the alternative and isn't usable — Sign in with Apple needs an Apple ID on
the device, and the places live on the server, so a fresh simulator has an empty
map.
