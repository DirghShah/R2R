# Store-sized screenshots

1320 × 2868 — Apple's 6.9" iPhone class, which App Store Connect requires.

Sources were shot on an iPhone 17 Pro at 1206 × 2622, the 6.3" class, which the
listing does not accept. Upscaled rather than reshot: the aspect ratios differ
by 0.065%, so no crop is needed and nothing is distorted. The Simulator was the
alternative and isn't usable here — Sign in with Apple needs an Apple ID on the
device, and the places live on the server.

Suggested listing order is the filename order: place detail leads, because it is
the screen that shows Nosh doing something no competitor does.
