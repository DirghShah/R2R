# Store screenshots — iPhone 6.5" class

1284 × 2778, which is what App Store Connect asked for on this account.

The sibling `store/` folder is 1320 × 2868, the 6.9" class. Apple's published
guidance says 6.9" is the required size for new apps, but this account's
console offered a 6.5" slot and rejected 6.9" files against it. The console is
the authority — use whichever slot it actually shows.

Both sets come from the same 1206 × 2622 originals shot on an iPhone 17 Pro.
